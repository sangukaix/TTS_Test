나와 대화하는 아바타 · Windows 64비트용

1. ZIP 파일의 압축을 모두 풉니다.
2. 폴더의 Start.cmd를 더블 클릭합니다. 기본 브라우저에서 앱이 열립니다.
3. ‘AI API 설정’에서 기본 모델인 Google Gemma 4 E2B 옆의 ‘모델 다운로드’를 한 번 누릅니다.
   Qwen3.5 2B를 쓰려면 목록에서 선택하고 해당 모델을 다운로드합니다.
4. 음성 입력을 지원하는 브라우저에서는 마이크를 허용하고 버튼을 누른 채 말해 보세요.

페르소나와 음성 설정은 바꾸면 자동으로 저장되고 적용됩니다.
모델을 받은 뒤에는 API 키나 인터넷 없이 로컬 모델로 답변을 만들 수 있습니다.

클라우드 AI를 사용하려면 ‘AI API 설정’에서 서비스와 모델을 고르고,
본인의 API 키를 입력하면 자동 저장됩니다. 옆의 ‘키 삭제’ 버튼으로 지울 수 있습니다.
사용 조건과 비용은 선택한 서비스 계정을 따릅니다.
저장한 API 키는 이 컴퓨터의 브라우저 프로필에 보관됩니다.

Supertonic 3, Mimic 3, MeloTTS Korean, Kokoro는 앱에 포함되어 있습니다.
노트북의 마이크 인식은 브라우저에서 처리합니다.
앱을 사용하는 동안 Start.cmd가 연 창을 두고, 사용이 끝날 때 그 창을 닫으면 됩니다.
